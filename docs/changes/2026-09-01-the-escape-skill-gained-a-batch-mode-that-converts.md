## Change

The escape skill gained a batch mode that converts an over-engineering review's tagged finding list into escape rows, behind a filter for loop-produced code

## Evidence

judgment

## Result

A complexity-only review lens runs often and yields nearly every time, but nothing it found reached the escape log, so the class of defect it covers reads as near-absent in the flywheel while actually being the most frequently found. The batch mode maps its finding tags onto the existing class vocabulary and reuses the post-hoc sweep's stage value so both sweeps stay one comparable series. The filter is the load-bearing half: most of what a complexity lens reports is pre-existing debt, which is not an escape and would inflate every gate ratio with no way to separate it afterward.
